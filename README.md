# Clear Air Advisor

The app and its API functions are in [`clear-air-advisor/`](clear-air-advisor/).

For features, local setup, API configuration, tests, and deployment instructions,
see the [full project README](clear-air-advisor/README.md).

To run locally, first open the app folder:

```powershell
cd clear-air-advisor
.\scripts\dev.ps1
```

Keep API keys in `clear-air-advisor/.env.local`; never commit them.
