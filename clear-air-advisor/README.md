# Clear Air Advisor

**A GenAI urban air quality assistant for India — PromptWars Challenge 6.**

Clear Air Advisor helps families and communities navigate severe winter smog and urban
air pollution. It reads live air composition for any town in India, converts it to the
official **CPCB National AQI** scale, adds a 48-hour smog outlook, and produces a
household action plan — a low-emission daily routine, indoor air measures and
sustainable alternatives — with the direct impact of every choice quantified and
labelled as an estimate.

No framework or build step. Vercel Functions under `/api` keep provider keys on the
server instead of exposing them in browser code.

---

## Features

- **CPCB National AQI engine** — pollutant concentrations are converted with the
  statutory sub-index breakpoints (CPCB Expert Group, 2014) for PM2.5, PM10, NO₂, O₃,
  CO, SO₂ and NH₃. The overall index is the maximum sub-index; the dominant pollutant
  is reported. Each pollutant is shown against its WHO 24-hour reference level.
- **48-hour smog outlook** — hourly index trajectory as a dependency-free SVG chart with
  category bands, the cleanest ventilation window, the worst stretch of the next
  24 hours, a four-day daily-maximum view and an improving / stable / worsening trend.
- **Household action plan** — generated by Gemini (`gemini-3.5-flash-lite`) as JSON from
  live air data, weather, the outlook and a household profile (members, commute mode,
  cooking fuel, home type, budget, goal). Rendered as three sections with the impact of
  every item: exposure avoided, PM2.5 reduction, CO₂e saved, rupee cost.
- **Follow-up advisor chat** — ask about today specifically ("should my father take his
  morning walk now?"); the model answers against the same live context.
- **Offline advisory engine** — if Gemini is unreachable, misconfigured or rate-limited,
  a deterministic rules engine produces the same plan and chat answers from the same
  live data, clearly labelled. The demonstration cannot break on stage.
- **Synthetic data mode** — if even the weather feed is unreachable, a deterministic
  per-city bundle keeps the interface alive, labelled "Demo data · feed offline".
- **India-wide location search** — an offline dataset of 100+ cities covering every
  state and union territory, backed by the OpenWeatherMap geocoder for any town or
  village. Browser geolocation with reverse geocoding is supported.
- **Practical details** — print stylesheet for a paper copy of the plan, copy-to-
  clipboard plain text, keyboard-navigable combobox, reduced-motion support, visible
  focus states, responsive from 320 px phones to desktops.

## Quick start

```bash
git clone https://github.com/<you>/clear-air-advisor.git
cd clear-air-advisor
npm install -g vercel
```

Copy `.env.example` to `.env.local`, add your **rotated** provider keys there, then
run `.\scripts\dev.ps1` in PowerShell. The script loads the local values into the
Vercel Functions process without printing them. The app and API functions will be
available at `http://localhost:8082`. A plain static server (such as
`python -m http.server`) cannot run the API functions.

With valid provider keys configured, the app opens on New Delhi with live data.
Without keys, it uses labelled synthetic data and the offline advisory engine.
Choose any city, fill the household section, then press **Generate my action plan**.

### API keys

| Service | Used for | Where it lives |
|---|---|---|
| OpenWeatherMap | geocoding, current weather, air composition, 96-hour pollution forecast | `OPENWEATHER_API_KEY` in `.env.local` or Vercel project Secrets |
| Gemini | action plan and chat (`gemini-3.5-flash-lite`) | `GEMINI_API_KEY` in `.env.local` or Vercel project Secrets |

For local development, copy `.env.example` to `.env.local` and fill in the values.
Run `.\scripts\dev.ps1` in PowerShell so the function runtime receives them.
For Vercel, add both variables in **Project Settings → Environment Variables** as
Secrets for Development, Preview, and/or Production, then redeploy. Never use a
`NEXT_PUBLIC_` prefix for either key.

**Security note.** Do not commit `.env.local` or paste API keys into the browser.
The API routes keep keys server-side, but a public deployment can still receive
requests from anyone; set Gemini usage limits and configure Vercel Firewall
rate-limiting before publishing a paid key.

## How it works

```
browser (static site)
  ├─ js/cities.js    offline city dataset (every state/UT) + instant search
  ├─ js/aqi.js       CPCB sub-index engine · pollutant bars · 48-hour SVG chart
  ├─ js/api.js       same-origin client for the provider API functions
  ├─ js/advisor.js   AI plan (JSON mode) + advisor chat + offline rules engine
  ├─ js/app.js       UI state, combobox, profile, rendering, API setup dialog
  └─ js/config.js    public model settings and browser preferences
  api/
  ├─ weather.js      validated OpenWeatherMap proxy
  └─ gemini.js       bounded Gemini content-generation proxy
```

1. A location is resolved (offline dataset, geocoder, or geolocation).
2. Weather, air composition and the 96-hour pollution forecast are fetched in parallel.
3. `aqi.js` computes the CPCB-style index, windows, daily maxima and trend.
4. `advisor.js` assembles a compact context (place, index, pollutants, windows,
   weather, profile) and requests the plan as JSON; validation is field-by-field and
   any failure falls back to the rules engine.
5. Follow-up chat reuses the same context plus the last few exchanges.

## AQI methodology

Each pollutant is mapped to a sub-index by linear interpolation across the statutory
CPCB concentration breakpoints, and the overall index is the maximum sub-index:

| Pollutant | Averaging | Breakpoints (concentration → sub-index) |
|---|---|---|
| PM2.5 (µg/m³) | 24-h | 0–30 → 0–50 · 30–60 → 50–100 · 60–90 → 100–200 · 90–120 → 200–300 · 120–250 → 300–400 · 250+ → 400–500 |
| PM10 (µg/m³) | 24-h | 0–50 → 0–50 · 50–100 → 50–100 · 100–250 → 100–200 · 250–350 → 200–300 · 350–430 → 300–400 · 430+ → 400–500 |
| NO₂ (µg/m³) | 24-h | 0–40 → 0–50 · 40–80 → 50–100 · 80–180 → 100–200 · 180–280 → 200–300 · 280–400 → 300–400 · 400+ → 400–500 |
| O₃ (µg/m³) | 8-h | 0–50 → 0–50 · 50–100 → 50–100 · 100–168 → 100–200 · 168–208 → 200–300 · 208–748 → 300–400 · 748+ → 400–500 |
| CO (mg/m³) | 8-h | 0–1.0 → 0–50 · 1–2 → 50–100 · 2–10 → 100–200 · 10–17 → 200–300 · 17–34 → 300–400 · 34+ → 400–500 |
| SO₂ (µg/m³) | 24-h | 0–40 → 0–50 · 40–80 → 50–100 · 80–380 → 100–200 · 380–800 → 200–300 · 800–1600 → 300–400 · 1600+ → 400–500 |
| NH₃ (µg/m³) | 24-h | 0–100 → 0–50 · 100–200 → 50–100 · 200–400 → 100–200 · 400–800 → 200–300 · 800–1200 → 300–400 · 1200+ → 400–500 |

**Honest caveat.** CPCB breakpoints are written for 24-hour (or 8-hour) means; the live
feed reports instantaneous model concentrations. The app therefore displays an
*estimate of the statutory index*, and says so in the interface. Category colours and
health advisories follow CPCB wording.

## Engine and API verification

The CPCB maths is covered by a Node test harness (33 assertions: breakpoint anchors,
interpolation, unit conversion of CO from µg/m³ to mg/m³, dominant-pollutant selection,
partial-data validity, category boundaries, forecast window and trend logic):

```bash
node scripts/test_aqi.js   # 33 passed, 0 failed
node scripts/test_api.js   # server-side key handling and request validation
```

## Browser support

Any modern browser (Chromium, Firefox, Safari). Uses `<dialog>`, `fetch`, ES5/ES6
JavaScript, and CSS grid. No polyfills, no network calls beyond the two APIs and
Google Fonts (with system-serif fallbacks).

## Limitations, stated plainly

- The index is an estimate derived from instantaneous model data, not a CPCB station
  average (see methodology caveat).
- Quantified impacts in the plan are engineering estimates from published emission
  factors (for example, petrol car ≈ 0.17 kg CO₂e/km, two-wheeler ≈ 0.11, metro ≈ 0.04
  per passenger-km; N95 respirators filter ≥ 95 % of PM2.5 when fitted). They are
  labelled as estimates so you can judge them.
- Nothing here is medical advice; during severe episodes follow your doctor and
  official CPCB / SAFAR bulletins.
